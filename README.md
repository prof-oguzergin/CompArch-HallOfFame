# Computer Architecture Hall of Fame

A unified Hall of Fame page for top computer architecture conferences: **HPCA**, **MICRO**, **ISCA**, **ASPLOS**, and **IEEE Micro Top Picks**.

## Live Site

Visit: [https://comparch.oguzergin.net](https://comparch.oguzergin.net)

## Features

- **Combined view**: See researchers ranked by total papers across all venues
- **Individual venue tabs**: HPCA, MICRO, ISCA, ASPLOS, IEEE Top Picks
- **Search**: Filter by researcher name
- **Sortable columns**: Click any column header to sort
- **Multi-venue highlighting**: Researchers appearing in all 4 major venues are highlighted
